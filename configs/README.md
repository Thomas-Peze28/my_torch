# Network configuration files

JSON files describing networks to create with `my_torch_generator`. Format: [docs/usage.md](../docs/usage.md#5-configuration-files).

- `chess_network.conf`: the pushed `my_torch_network.nn`.
- `chess_network_256.conf`: the previous, smaller one, kept for the benchmarks.
- `basic_network.conf`: a small network, quick to train.
- `benchmarks/`: the networks compared in [docs/results.md](../docs/results.md).
